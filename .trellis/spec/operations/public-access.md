# 本站公开登录规则

修改登录、注册、OAuth、邀请码领取或设置页绑定流程前使用。规则由站长于2026-11-21明确选择，不是可被客户端参数覆盖的展示偏好。

- 公开登录/注册仅使用Discord；`src/lib/auth/access-policy.ts`集中提供登录源、管理员密码资格和群ID解析。
- Discord授权和回调都必须配置至少一个允许群；每次登录/绑定检查成员资格与待验证状态。邀请参数或旧cookie不能替代群检查，配置或外部验证失败不放行。
- 邮箱注册、公开领码与LinuxDo授权/回调在服务端返回403，且在解析、占码、建号或外部请求前停止。后台历史配置与记录不等于重新开放公开入口。
- `/login`为服务端Discord入口，不初始化密码表单/Turnstile；`/login?admin=1`仅展示恢复表单。密码接口保留验证码、限频、封禁和验密，验密成功后才允许数据库角色ADMIN。错误密码和未知邮箱继续使用相同401响应，客户端role不授予权限。
- 旧有效会话与API Key不主动撤销；普通邮箱或旧LinuxDo用户可在仍登录的设备上绑定Discord，复用原User和数据，不凭相同邮箱合并账号。已退出且未绑定的旧用户需管理员处理。
- 普通用户不能解绑唯一Discord登录；管理员仍须满足原密码恢复条件。设置UI的绑定/解绑可用性须与服务端相同；其他旧OAuth来源不能遮住Discord改绑入口。
- 群资格只在新登录/绑定时复核，没有后台退群同步。站内封禁仍在每请求授权检查，不能将保留旧会话描述为已实现即时退群撤权。
