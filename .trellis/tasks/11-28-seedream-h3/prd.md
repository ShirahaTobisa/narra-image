# 接入 Seedream 5.5 与 H3 视频

## Goal

接入 APIMart Seedream 5.5 图片及 h3.coolhs.com H3 视频，复用现有渠道、队列和扣费。

## Requirements

- Seedream 模型 ID seedream-5-5，固定1K、最多一张参考图、每次一张输出。
- H3 对外模型 ID h3；基础文生/单图生视频，4/6/8秒、最长边1440。
- 两者跳过本站内容审核；GPT审核、封禁、人工暂停、限额和计费保留。仅服务端可信渠道决定跳过。
- 新模型不得被 GPT 的 wildcard 渠道接走。
- 视频透传，上游保留3天；播放、封面和下载只访问本站URL，不向浏览器暴露上游地址或卡密，不落地视频。
- Seedream 图片仍临存1小时。公开广场和头像审核保持原规则。
- 没有真实密钥时不声称实测出图/出片，不开放未配置渠道。
- 用户后续确认复用 New API 现有 APIMart 密钥并接通 Seedream；H3 等用户回来后再配置，保持关闭。
- 两个模型各每天全站10次，每个账号每个模型每天1次，先到先得；UTC+9零点重置，排队占名额，明确失败或提交前取消退回。网页、Canvas、API共用，不因删历史/换API Key/重启刷新额度。

## Acceptance Criteria

- [x] 网页/API参数限制、审核分流和按张计费一致。
- [x] 两模型各每日10次、每账号每模型每日1次，真实数据库并发和失败恢复验证通过。
- [x] Seedream异步任务、H3上传/幂等/轮询和授权流式代理的离线测试通过。
- [x] GPT回归、相关lint/类型/Go构建和契约检查通过。
- [x] 交付后台配置说明与真实验证范围（delivery.md、validation-db.md）。
