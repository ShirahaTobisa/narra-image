## Prisma 错误映射

使用缓存应用镜像中的 Prisma Client 7.10.1，仅连接本轮临时数据库。实际捕获结果：

- `$executeRawUnsafe`：外层 `code = P2010`。
- `generationJob.create`：外层 `code = P2039`。
- 两种调用均在 `error.meta.driverAdapterError.cause` 中携带 `originalCode = P0001`。
- `originalMessage` 为 `MODEL_DAILY_QUOTA_USED` 或 `MODEL_DAILY_QUOTA_EXHAUSTED`，同层 `code/message` 也携带相应数据库信息。

因此不能只按外层 Prisma 错误码识别配额；当前按固定业务标记提取的映射方式适配实际返回结构。
