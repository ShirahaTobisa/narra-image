# 保留图生图，增加独立图片预审

## 目标与事实

用户明确图生图是核心能力，不能通过关闭参考图来降低审核风险。继续已授权的安全修复与发布，保留普通上传、历史引用、Canvas 与外部 API 图生图。

当前代码与线上版本为 b318b6e；普通 omni 审核已覆盖实际原图，但没有第二个独立图片检测器。普通模型的 sexual/minors 仅覆盖文字。2026-11-20 用现有审核密钥查询专用 `omni-moderation-csam-latest`，并用明确无害的纯色PNG对审核端点确认，均返回404/model_not_found；没有提交用户图片，不能认为已有专用服务权限。

## 要求

- 在调用外部审核/生图服务前增加服务器端独立图片色情预审，逐张检查参考图，不能依赖客户端结果。
- 正常真人照片和二次元参考图继续可用；不按“有人物/有儿童”一刀切，不改变最终送去生成的原图字节或顺序。
- 优先使用现有 Sakura 的 CPU；不擅自购买服务、申请账号或提交第三方入驻资料。
- 图片推理不能阻塞登录/页面主线程；加载复用、并发和等待均有界，异常按现有审核不可用逻辑处理。
- 独立预审只能作为额外 NSFW 过滤层，不宣称是专用 CSAM 识别、人物年龄证明或账号免封保证。专用检测仍需服务方授权。
- 不收集、下载或用真实违规内容测试。真实模型仅跑明确无害图片；拒绝/失败行为使用模拟结果验证。

## 验收

- [ ] 验证选型在 Node24/生产 Linux 环境的兼容性、内存和耗时，正常图生图不被整体关闭。
- [ ] 预审拒绝/超时/崩溃时不请求外部审核、生图、不入队、不扣费；普通无害输入保持原字节。
- [ ] 类型、lint、相关/完整测试、生产构建和独立审阅通过。
- [ ] 依赖/模型来源固定，维护文档与可回退发布记录完整，线上无害验证通过。

## 范围边界

不新增数据库迁移，不更换生图渠道，不做真人年龄识别；不把提高拦截率宣传为零漏检。保留用户账号控制与现有总审核门禁。
