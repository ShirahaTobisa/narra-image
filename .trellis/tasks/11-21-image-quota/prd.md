# 按张计费和限额

用户确认：RPM 限制的目的为每个用户一分钟最多提交生成 5 张图片。保留每次 1～4 张选择；图生图保留且实际只生成 1 张。此前已授权修复、推送 GitHub 和部署，本次继续执行。

## 验收
- 文生图 4 张、单价 5 时扣 20，余额 19 不创建任务、不扣费，余额 20 可提交。
- 图生图多张参考图仍只按 1 张输出计费；篡改 count 不改变该规则。视频沿用一次任务单价，自填渠道沿用零积分。
- 每用户滚动 60 秒最多接受 5 张输出；4 张后请求 2 张被拒，剩余 1 张仍可用。拒绝返回 429，不扣费、不提交上游。
- 网页、Canvas、外部 API 和网关按同一个用户共用限额，更换 API Key 不增加额度；Canvas 已提交请求重放不重复消费图片额度。
- 确定失败按照实际扣费金额退款一次，任务状态不明时保留既有退款规则。
- 不修改历史余额、不启用当前禁用功能，不改变审核和图生图能力。
- 完成回归、独立检查、提交推送和 Sakura 应用部署，验证线上健康。
