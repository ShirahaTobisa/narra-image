# 设计

新增 UserIpAddress 表，账号/IP 联合主键、首次/最近时间、IP 查询索引，账号删除级联。只追加迁移。
Caddy 覆盖 X-Narra-Client-IP 为 TCP 对端地址，应用端口继续仅本机可达。业务只读该头，拒绝自报转发链。
共享记录器在成功登录、有效会话访问及 API Key 验证后调用，以 Next after 异步写入。同账号/IP 五分钟合并，缓存有上限，失败可重试。
管理员页面 /admin/users/ips 全站汇总同 IP 多账号，可切换全部 IP，并搜索/分页；用户管理页增加入口。
先隔离验证和构建，再备份数据库/配置、迁移、覆盖代理头、候选验证、发布。回滚恢复旧应用和代理配置，保留兼容的新表。
