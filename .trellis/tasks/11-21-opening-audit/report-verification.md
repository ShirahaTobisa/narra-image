# 开站报告逐项复核

依据用户提供的 `D:/tools/claude/reports/narra-image-开站排查-2026-11-21.md`。报告基线为 ff5dfec，本轮开始时线上为 1c50f24，Git 文档头为 da7915a；报告中的建议没有被当作修改运营规则或发布公告的授权。

| 项 | 结论与处理 |
| --- | --- |
| 1 并发和空间 | 实际是全站2个活跃任务、每人1个，并非只能同时生成2张；每任务可含多张。5GB硬上限和每输出50MiB预留成立，现有占用下约95个输出名额。30分钟预备超时由相关查询触发，不是必定准时执行的后台定时器。保留既定并发、配额和维护开关。 |
| 2 公开昵称 | 已修：投稿者可选匿名或署名，默认匿名；服务端审核并保存昵称快照，改账号昵称不改变已投稿署名。旧数据不回填，公开头像/邮箱不暴露；管理员看到实际投稿署名，旧审核页面不能批准撤回重投后的新版本。封禁立即隐藏公开作品，解封恢复原已批准状态。 |
| 3 兜底模型、空图 | 已修：普通用户只能请求公开模型列表中的明确名称，已知模型仍可兜底；模型列表不暴露通配符。无参考图的普通JSON图生图在入队前拒绝，参考图输入错误不污染渠道健康。 |
| 4 多图扣费 | 上轮1c50f24已上线：4张按4倍单价收费，占4个图片额度；每用户滚动60秒最多申请5张，网页/API/Canvas共用。图生图仍保留且单次输出1张。 |
| 5 退群资格 | 群资格仅在Discord登录回调检查，已有网页会话最多保留原剩余14天；API若开启，Key还可能更久。站内封禁即时阻止后续授权，但退群同步需要额外凭据/同步机制，本轮没有虚称已实现。 |
| 6 删除后重注册 | 成立，但只能管理员删除，非用户自删。已补删除确认：删除不能代替封禁，会清除关联身份与记录，同一第三方身份可能重新注册获赠。没有擅改为永久保留身份或改变赠送政策。 |
| 7 满队列仍存图 | 已修：普通网页先原子占名额和扣费，准备期间Worker不能领取；成功取得名额后才预留输出、保存参考图，再条件启用。失败复用一次退款，处理取消/封禁以及提交回执丢失。部分上传失败的对象仍服从既有保留/清理规则，未承诺所有存储异常都零残留。 |
| 8 本地拒绝计次 | 已按用户确认修复：站内明确违规与上游内容拒绝合并为滚动24小时3次暂停；超时、格式无法判断和审核服务故障不记违规，查询失败也不放行。头像和公开署名共用该门禁；同次预审拒绝不建生成任务，不重复计数。 |
| 9 头像 | 已修：每用户5次/60秒上传限制，200KiB上限，原始图片经过格式、本地及远端审核后才保存；失败不写S3或账号。线上当前未配S3，回退是个人资料data URL，不是报告所称新增本站公开media链接。旧头像不自动补审，公开作品继续不显示头像。 |
| 10 带宽 | Sakura官方说明试用期限制出站10Mbps，但无法仅凭HTTP响应或试用资格判定本机当前是否仍处试用。没有调整套餐、网络或Cloudflare配置。[官方FAQ](https://vps.sakura.ad.jp/faq/) |
| 11 注册和措辞 | 已按用户确认修复：公开邮箱注册、领码和LinuxDo入口服务端关闭，公开登录仅Discord并必须验证群成员。管理员在/login?admin=1恢复，后台仍验证真实ADMIN角色；密码错误不暴露角色差异。旧有效会话可将邮箱/LinuxDo账号绑定Discord，保留原数据，不按邮箱自动合并。普通用户不能解绑唯一Discord。生产只读确认Discord配置有效、无LinuxDo配置行且管理员密码恢复可用。 |
| 12 审核低限制 | 已修：内置渠道隐藏无效的审核策略选择；服务端既有强制审核保持，自填渠道开启时沿用其原选项。 |
| 13 首页宣传 | 已修：虚构累计作品/模型数/平均速度改成实际数量限制；关闭API或读取配置失败时隐藏能力介绍，页面描述不再承诺已关闭的自填渠道。保留原项目和修改版源码、许可证署名。 |
| 14 提示词内容 | 空库/同步未开属于内容准备，不视为接口故障；未自动开启外部同步，未擅自删开源链接。社区规则是否限制某些外链需另行核实。 |
| 15 审核排队 | 本地模型1个运行、2个等候，容量满或故障时拒绝继续生成，是现有资源保护。保留失败即拦截，不扩到超过服务器能力，也不把拒绝改为放行。 |
| 16 不明结果退款 | legacy超时或结果保存失败仍可能全额退款，不能据此保证上游没有产生费用；不能说已成功入库展示的任务还会被普通补偿再次退款。生产v1仍关闭，本轮没有未经完整状态处理验收就切开关或擅改失败收费规则。 |
| 17 封禁排队任务 | 已修：Worker首次向上游发送前再次检查封禁，确认未提交的任务取消并按记录补偿一次；已开始发送的批次不被新封禁误判为未提交并全额退款。 |
